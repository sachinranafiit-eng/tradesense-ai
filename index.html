Indian-market production connection

For broker-grade Indian real-time ticks and option/futures instruments, connect an authenticated broker/exchange feed (for example Upstox Market Data Feed V3) through a secure backend. Do not expose broker access tokens in a public HTML page.

Production architecture: Browser → your secure server → broker market-data WebSocket → candle builder → scanner → browser. Keep order placement separate and require explicit user confirmation.
